# 🚀 Someshwara UI Project (React JS)

## 📌 Overview

The **Someshwara UI Project** is a frontend-focused project aimed at improving the existing user interface without altering the core design elements like colors and typography.

This project highlights my ability to enhance UI/UX while maintaining design consistency.

---

## 🎯 Objective

- Improve UI components and layout
- Enhance user experience without changing:
  - 🎨 Color scheme
  - ✍️ Typography

- Focus purely on **UI enhancement and visual structure**

> ⚡ Project completed in 3 days
>
> - 1 day: UI Design (Figma)
> - 2 days: UI Development (React JS)

> 📌 Note: UI is ~85% completed

---

## 🛠️ Tech Stack

- ⚛️ React JS
- 🎨 Tailwind CSS
- 🎭 Framer Motion (Animations)
- 🔣 React Icons
- ⚡ Vite
- 🧩 Figma (UI Design)
